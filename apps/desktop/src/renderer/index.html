设置

任务进度和完成提醒在悬浮提醒窗里。这里只管理设备与偏好。

环境

先启用运行 Agent 的环境。远程 Linux 请点「添加设备」。连接后，按下面的接入指引发起第一个任务。

Codex CLI
打开 codex，在对话里输入 /hooks。核对带有 vibemate-hook-runner 的命令指向自己的安装目录，再信任新增或已更改的条目。
GitHub Copilot CLI
重启 copilot 加载 Hook。若首次打开项目时询问是否信任目录，核对当前目录后确认。
Claude Code
在项目目录重新打开 claude。交互会话首次询问工作区信任时，核对目录后确认。
Antigravity
新开会话。若未收到任务，在 CLI 的 /hooks 中检查 vibemate-monitor 是否启用。

发一条任务，展开桌面胶囊，确认列表里出现对应的设备名和任务标题。

提醒

悬浮提醒窗总会显示是哪台设备、哪个项目。系统通知适合不在电脑前或全屏时。

桌宠关注范围

范围外的审批和错误只显示角标，不会抢占桌宠动画。悬浮监控窗始终显示全部环境。

添加 Linux 设备

填写设备登录信息，测试成功后即可安装并开始监控。支持 Linux 电脑和树莓派。

使用平时运行 Agent 的 Linux 用户，接收端和 Hook 将安装到该用户目录。

密码和密钥口令仅在本次应用运行期间保留。下次启动需重新输入；私钥只从所选文件读取。

测试连接只检查登录与设备环境。开始监控会部署接收端并注册 Agent Hook；完成后请重启 Agent 会话。
